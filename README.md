# Ежемесячная супервизия — личный рабочий трекер

Простое статическое приложение для GitHub Pages. Данные хранятся локально в браузере (`localStorage`).

## Что умеет

- три направления работы: ПСТБИ, Школы, Олимпиады;
- проекты и задачи с помесячной историей;
- быстрый ввод задач;
- план, срок, приоритет, рабочий статус, итог и фактический результат;
- мастер закрытия месяца с массовым переносом незавершённых задач;
- автоматическое создание записи задачи на следующий месяц при переносе;
- сравнение месяцев;
- ежемесячные срезы CRM ПСТБИ по 11 стадиям;
- журнал супервизий;
- CSV-выгрузки, печать/PDF и резервная копия JSON.

## Публикация через GitHub Pages

1. Создайте новый репозиторий GitHub.
2. Загрузите в корень репозитория `index.html`, `app.js`, `styles.css` и `.nojekyll`.
3. В Settings → Pages выберите публикацию из ветки `main`, каталог `/ (root)`.
4. Откройте адрес GitHub Pages, который покажет GitHub.

## Важно о данных

Данные не хранятся в GitHub и не синхронизируются между устройствами. Они находятся только в текущем браузере. Регулярно используйте «Выгрузка → Резервная копия JSON».
